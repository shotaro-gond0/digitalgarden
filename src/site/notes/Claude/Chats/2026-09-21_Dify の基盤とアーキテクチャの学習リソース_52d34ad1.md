Dify を全体的に把握するには、以下のような学習経路がお薦めです：

## 📚 **公式リソース**

**1. 公式ドキュメント（docs.dify.ai）**
- アーキテクチャ、デプロイメント方式、全機能の詳細説明
- セルフホスティングガイド、API リファレンス

**2. GitHub リポジトリ**
- Docker Compose でのクイックスタート（最小要件は CPU ≥2 Core、RAM ≥4 GiB）
- ソースコード構造、コントリビューション向けガイド

## 🎓 **ハンズオン学習**

**3. Dify Workshop（公式チュートリアル）**
- legacy-docs.dify.ai/workshop に初級者向けの段階的実験ガイドがあり、前提知識不要で基礎概念から実践的な内容まで学べる
- 各実験に詳細な手順と説明が付属

**4. 実践的なプロジェクト例**
- 「Master Dify.ai」では、カスタマーサービスボット・RAG・エージェント・ワークフローなど、ステップバイステップで実装プロジェクトを手掛けられる
- 180,000+ デベロッパーが利用中の学習プラットフォーム

**5. AWS マーケットプレイスワークショップ（日本語版）**
- AWS 上でのデプロイメント、RAG チャットボット、エージェント、ワークフロー構築を実践するマルチパート形式
- 実運用寄りの構成学習

## 🏗️ **アーキテクチャ理解**

Dify のコア機能は Workflow（ビジュアルキャンバス上のワークフロー構築）、RAG パイプライン、50+ 組み込みエージェントツール、LLMOps（ログ・性能分析）で構成され、すべての機能に対応する API が提供されるため、独自ビジネスロジックへの統合が容易です。

**学習の流れ：** Docker で起動 → Workshop 実験 → 公式ドキュメント（需要に応じて参照）→ Master Dify.ai でプロジェクト実装 → AWS ワークショップで本番構成を学ぶ、というのが効率的です。
